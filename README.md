# theoretical-math-applications

Applications of theoretical math to recorded subjects: the wire experiment,
the JEV seat comparison, the fleet, and EIT/SAT. Each application exists only
where the subject's own object, measurement, and decision can be named;
otherwise the entry is labeled analogy, design, or void. A diagnostic is not
a theorem, and a null must match the construction it tests.

## Contents

- `theoretical-equations-and-rederivations.md` — equations in the form used,
  with re-derivations (R-C0, R-A1, R-A2, R-ANA, R-C1, R-V01).
- `theoretical-math-applications-spudcell-wire-fleet.md` — attempts A1–A8
  and cross-subject X1–X3, each pinned or recorded as not applied. No theorem
  applies in its own form anywhere yet, except calibration case C-0 (Cheeger
  bound on the EIT mesh).
- `two-theorems-comparison-map.md` — Komlós vs Kelley–Meka across all 20
  subject events on record.
- `all-theories-map-sections-1-7.md` — labeled excerpt (§§1–7) of the
  all-theories map. §8 is held in the private `research-private` repo.
- `SETTLED-VERDICTS.md` — confirmed and refuted theory IDs from
  `theories-full-inventory.md`, with the basis each entry states, including
  the Counts-table-vs-entry mismatches found at build time.
- `trials/` — JEV discrepancy, wire AP, and V-01 threshold-sweep protocols,
  results, scripts, and per-leg JSONs (same set as in `wire-experiment`
  `docs/ap-trials/`).
- `ap_yardstick.py` — the closed-form uniform-null yardstick (pure arithmetic).
- `why-confidence-degenerate.md` — why the fast-confidence escalation leg
  never fires on saved rows.

## Status labels kept

Verdicts are the assistant's, labeled as such. Nulls stay nulls. The N10
residual is fragile (+0.012%, observed inside the null range at the finest
profiling). The V-01 refutation stands (threshold inert on saved rows).
